# spec.md — URL to Markdown

## 개요

웹 페이지 URL을 입력하면 본문을 Markdown으로 추출해 보여주는 단일 페이지 서비스. 사용자는 결과를 복사·다운로드하거나, 선택한 프롬프트와 함께 ChatGPT·Claude에 바로 넘길 수 있다.

## 범위

### 포함
- URL 입력 및 지우기
- Markdown 변환 (defuddle 라이브러리)
- 결과 렌더링 (페이지 제목·저자 헤더 UI + Markdown HTML 렌더링)
- 내보내기: 복사 / .md 파일 다운로드
- ChatGPT·Claude로 열기 (클립보드 복사 + 새 탭)
- 프롬프트 프리셋 3종 및 직접 입력 (1회용)
- 다크모드 토글

### 제외
- 로그인·회원가입 (공개 서비스, 인증 불필요)
- 변환 히스토리 저장 (새로고침 시 초기화, 세션 범위)
- 프롬프트 커스텀 저장 (직접 입력은 1회용)
- 모바일 전용 UI 분기 (반응형으로 처리, plan.md 소관)

## 시나리오

### 1. URL 입력 후 Markdown 변환

- **Given** — 빈 URL 입력창이 표시된 초기 화면
- **When** — 사용자가 유효한 웹 페이지 URL을 붙여넣고 "변환" 버튼을 클릭한다
- **Then** — 결과 영역에 페이지 제목·저자 헤더가 별도 UI 섹션으로 나타나고, 그 아래 추출된 본문이 렌더링된 HTML로 표시된다

성공 기준:
- [ ] 유효한 URL 입력 + 변환 클릭 → 결과 영역에 페이지 제목 텍스트가 나타난다
- [ ] 유효한 URL 입력 + 변환 클릭 → 결과 영역에 저자 정보가 나타난다 (저자 정보가 있는 페이지 기준)
- [ ] 유효한 URL 입력 + 변환 클릭 → 본문 텍스트가 렌더링된 HTML 형태로 표시된다 (raw Markdown 소스가 아님)

### 2. 변환 중 로딩 상태

- **Given** — URL을 입력하고 "변환" 버튼을 클릭한 직후
- **When** — 서버가 응답을 처리하는 동안
- **Then** — 버튼 또는 결과 영역에 로딩 인디케이터가 표시되고 중복 제출이 불가하다

성공 기준:
- [ ] 변환 클릭 후 응답 전 → "변환" 버튼이 비활성화(disabled)되거나 로딩 상태로 바뀐다

### 3. 잘못된 URL 또는 접근 불가 사이트

- **Given** — URL 입력창에 형식이 잘못된 URL 또는 접근할 수 없는 주소가 입력되어 있다
- **When** — 사용자가 "변환" 버튼을 클릭한다
- **Then** — URL 입력창 아래에 에러 메시지가 인라인으로 표시되고, 사용자는 URL을 수정해 재시도할 수 있다

성공 기준:
- [ ] 형식이 잘못된 URL (예: `not-a-url`) → 입력창 아래 에러 메시지가 표시된다
- [ ] 접근 불가 URL → 입력창 아래 에러 메시지가 표시된다
- [ ] 에러 상태에서 URL을 수정하고 다시 변환 클릭 → 에러 메시지가 사라지고 변환이 재시도된다

### 4. URL 지우기

- **Given** — URL 입력창에 URL이 입력되어 있다 (결과가 표시된 상태 포함)
- **When** — 지우기(×) 버튼을 클릭한다
- **Then** — 입력창이 비워지고 결과 영역이 초기 상태로 돌아간다

성공 기준:
- [ ] URL 입력 중 지우기 클릭 → 입력창이 빈 상태가 된다
- [ ] 변환 결과 표시 중 지우기 클릭 → 결과 영역이 사라진다

### 5. Markdown 복사

- **Given** — 변환 결과가 화면에 표시되어 있다
- **When** — "복사하기" 버튼을 클릭한다 (프롬프트 선택 여부 무관)
- **Then** — Markdown 텍스트(헤더 포함)가 클립보드에 복사되고, 버튼에 복사 완료 피드백이 나타난다. 프롬프트가 선택된 경우 프롬프트가 Markdown 앞에 붙어 복사된다

성공 기준:
- [ ] 프롬프트 미선택 + 복사 클릭 → 클립보드에 제목·저자 헤더 + 본문 Markdown이 복사된다
- [ ] 프롬프트 선택 후 복사 클릭 → 클립보드에 프롬프트 텍스트 + 제목·저자 헤더 + 본문 Markdown이 복사된다
- [ ] 복사 클릭 직후 → 버튼이 "복사됨" 등 완료 상태로 잠깐 바뀐다

### 6. .md 파일 다운로드

- **Given** — 변환 결과가 화면에 표시되어 있다
- **When** — ".md 다운로드" 버튼을 클릭한다
- **Then** — Markdown 내용이 담긴 `.md` 파일이 다운로드된다. 프롬프트가 선택된 경우 프롬프트가 앞에 포함된다

성공 기준:
- [ ] 다운로드 클릭 → `.md` 확장자 파일이 브라우저 다운로드로 저장된다
- [ ] 다운로드된 파일에 제목·저자 헤더가 포함되어 있다
- [ ] 프롬프트 선택 후 다운로드 → 프롬프트 텍스트가 파일 상단에 포함된다

### 7. ChatGPT로 열기

- **Given** — 변환 결과가 화면에 표시되어 있다
- **When** — "ChatGPT로 열기" 버튼을 클릭한다
- **Then** — ChatGPT 사이트가 새 탭으로 열리고, Markdown 내용(프롬프트 선택 시 포함)이 클립보드에 복사된다. 화면에 클립보드 복사 완료 안내가 표시된다

성공 기준:
- [ ] "ChatGPT로 열기" 클릭 → ChatGPT 사이트(`chat.openai.com`)가 새 탭으로 열린다
- [ ] "ChatGPT로 열기" 클릭 → Markdown 내용이 클립보드에 복사된다
- [ ] 클릭 직후 → 화면에 "클립보드에 복사됨" 류의 안내 메시지가 표시된다

### 8. Claude로 열기

- **Given** — 변환 결과가 화면에 표시되어 있다
- **When** — "Claude로 열기" 버튼을 클릭한다
- **Then** — Claude 사이트가 새 탭으로 열리고, Markdown 내용(프롬프트 선택 시 포함)이 클립보드에 복사된다. 화면에 클립보드 복사 완료 안내가 표시된다

성공 기준:
- [ ] "Claude로 열기" 클릭 → Claude 사이트(`claude.ai`)가 새 탭으로 열린다
- [ ] "Claude로 열기" 클릭 → Markdown 내용이 클립보드에 복사된다

### 9. 프롬프트 프리셋 선택

- **Given** — 변환 결과가 화면에 표시되어 있고, 프롬프트 옵션이 보인다
- **When** — "요약해줘" / "한국어로 번역해줘" / "쉽게 설명해줘" 중 하나를 선택한다
- **Then** — 해당 프롬프트가 선택 상태로 표시된다. 이후 복사·다운로드·ChatGPT/Claude 열기 시 해당 프롬프트가 Markdown 앞에 붙는다

성공 기준:
- [ ] 프리셋 선택 → 해당 항목이 선택 상태(활성화 스타일)로 표시된다
- [ ] 다른 프리셋을 선택하면 이전 선택이 해제된다
- [ ] 선택된 프리셋 재클릭 → 선택이 해제되어 프롬프트 없는 상태로 돌아간다

### 10. 직접 입력 프롬프트

- **Given** — 변환 결과가 화면에 표시되어 있고, 프롬프트 옵션이 보인다
- **When** — "직접 입력" 옵션을 선택한다
- **Then** — 프리셋 옆에 텍스트 입력창이 나타나고, 사용자가 임의의 프롬프트를 입력할 수 있다

성공 기준:
- [ ] "직접 입력" 선택 → 텍스트 입력창이 나타난다
- [ ] 직접 입력창에 텍스트 입력 후 복사 클릭 → 입력한 텍스트가 프롬프트로 Markdown 앞에 붙는다
- [ ] 페이지 새로고침 또는 URL 지우기 후 → 직접 입력 내용이 초기화된다 (저장되지 않음)

### 11. 다크모드 토글

- **Given** — 페이지가 라이트 모드로 표시되어 있다
- **When** — 다크모드 토글을 클릭한다
- **Then** — 페이지 전체가 다크 테마로 전환된다

성공 기준:
- [ ] 토글 클릭 → 배경이 어두운 색으로, 텍스트가 밝은 색으로 전환된다
- [ ] 다시 토글 클릭 → 라이트 모드로 복귀한다

## 불변 규칙

**내보내기 콘텐츠 일관성**: 복사·다운로드·ChatGPT/Claude 열기 모두 동일한 콘텐츠(헤더 + 본문 Markdown, 프롬프트 선택 시 프롬프트 선행)를 사용한다. 내보내기 방식에 따라 콘텐츠가 달라지지 않는다.

- ChatGPT (`chat.openai.com`) / Claude (`claude.ai`) — 외부 서비스, 새 탭 열기만 사용
